## ⚙️ Run Locally

Clone the repository:

```bash
git clone https://github.com/abilasha24/my-portfolio.git
```

Navigate into the project:

```bash
cd my-portfolio
```

Install dependencies:

```bash
npm install
```

Start the development server:

```bash
npm run dev
```

Build for production:

```bash
npm run build
```
